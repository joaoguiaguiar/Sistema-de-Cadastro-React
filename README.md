Sobre

Este foi o meu primeiro projeto com React, onde explorei e apliquei diversos conceitos importantes da biblioteca. Durante o desenvolvimento, aprendi a criar um projeto React do zero, trabalhei com estados e hooks como o useState para gerenciar dados e interações dentro do sistema. Também aprendi a organizar a estrutura de componentes de maneira eficiente e a utilizar props para passar dados entre os componentes. O objetivo deste projeto foi construir um sistema de cadastro simples, que me permitiu aplicar e solidificar meus conhecimentos sobre React.

	•	JSX
	•	CSS
